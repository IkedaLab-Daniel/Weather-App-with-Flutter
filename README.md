# Weather App 🌤️

A Flutter weather application that fetches real-time weather data for Philippine cities.

## Live Demo
🌐 [https://ikedalab-daniel.github.io/cool-impressive-weather-app/](https://ikedalab-daniel.github.io/cool-impressive-weather-app/)

## Features
- Search weather by City and Province
- Real-time weather data from OpenWeatherMap API
- Display temperature, humidity, pressure, wind speed
- Clean and responsive Material 3 UI

## Getting Started
1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run` for mobile or `flutter run -d chrome` for web
